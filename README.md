# Installateur des outils Claude Bellerive (Mac et Windows)

Dans l'app **Terminal**, coller cette ligne puis appuyer sur Entrée :

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Bellerive-Properties/installer/main/install.sh)"
```

Sur un PC Windows, dans **PowerShell** (touche Windows, taper PowerShell,
Entrée), coller cette ligne puis Entrée :

```powershell
irm https://raw.githubusercontent.com/Bellerive-Properties/installer/main/install.ps1 | iex
```

Ce dépôt ne contient que ces petits scripts de démarrage, sans aucune clé ni donnée.
Les outils eux-mêmes sont dans un dépôt privé, accessible sur invitation.
